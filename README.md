# 🎮 Gaming Era

A full-stack gaming e-commerce web application built using **HTML, CSS, JavaScript, Node.js and Express.js**.

🌐 **Live Demo:** https://gamingera.onrender.com

## 🚀 Features

- 🛍️ Browse gaming products
- 🔎 Product search and filtering
- 🛒 Add products to cart
- ➕ Update cart quantities
- 💳 Checkout and order placement
- 📦 Order confirmation and order history
- 👤 Customer signup and login
- 🔐 Admin authentication
- 📊 Admin dashboard
- 🎮 Game inventory management
- 📋 Order tracking
- 👥 Customer account management
- 📱 Responsive user interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- JSON-based file storage

### Deployment
- GitHub
- Render

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Shyamm-A/GamingEra.git
cd GamingEra
```

### 2. Install backend dependencies

```bash
npm install --prefix backend
```

### 3. Start the server

```bash
node backend/server.js
```

### 4. Open the application

Open:

http://localhost:10000
